The Problem

Hidden Evidence Inside Every Photo

📷

EXIF Metadata Ignored

Every digital image carries hidden metadata — GPS coordinates, camera model, timestamp — yet most investigators lack tools to extract and analyze this data systematically.

🗺️

No Geolocation Timeline

GPS data embedded in images can place a suspect at a crime scene, but manually decoding DMS coordinates and mapping locations is time-consuming and error-prone.

⚠️

Manipulation Undetected

Photos edited in Photoshop or stripped of metadata raise red flags, but without automated anomaly detection these signs go unnoticed in bulk evidence.

⛓️

No Chain of Custody

Digital evidence requires cryptographic integrity verification. Without SHA-256 hashing and audit logs, evidence integrity cannot be proven in court.

Our Solution

Forensic Tool v2.0

A complete Python-based forensic investigation platform for digital image analysis

🔬

EXIF Extraction

Full metadata extraction — camera, timestamp, flash, ISO, focal length, aperture from JPG/JPEG/TIFF/PNG

🗺️

GPS Mapping

DMS → Decimal conversion, interactive Folium map with clustered markers and timestamped timeline

⚠️

Anomaly Detection

5 automated checks: missing EXIF, no timestamp, no GPS, software post-processing tag, no camera model

Forensic Report

Auto-generated HTML report with full evidence table, case ID, and analyst signature

🔐

Chain of Custody

SHA-256 hash for every file, timestamped analysis log in CSV, evidence IDs (EVD-001, EVD-002...)

📊

Multi-Format Output

HTML report + interactive map + CSV results + chain of custody CSV + raw JSON metadata

Reflection

Challenges & Future Improvements

⚠ Challenges Faced

PNG Format Limitation
PNG files rarely contain GPS/EXIF data — tool detects this and flags it accordingly.
DMS Coordinate Parsing
Different cameras encode DMS fractions differently — required robust rational number parsing with edge case handling.
Evidence Without Metadata
Stripped EXIF files still need to be processed gracefully without crashing the pipeline.
Folium Timestamp Layer
TimestampedGeoJson requires ISO 8601 format — had to build a custom ts_to_iso() converter.

🚀 Future Improvements

PyQt5 Desktop GUI
Replace CLI with a full desktop interface — drag & drop evidence folders, real-time analysis progress.
AI-Powered Anomaly Scoring
Train an ML model on known manipulated images to provide probabilistic tampering scores.
Bulk Video Support
Extend to MP4/MOV files — extract GPS tracks embedded in video metadata (Apple & Android).
Blockchain Chain of Custody
Record SHA-256 hashes on a local blockchain (Ganache) for immutable, court-admissible evidence logs.
